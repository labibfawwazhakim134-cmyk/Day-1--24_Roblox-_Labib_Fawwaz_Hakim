1. Ringkasan Materi

Prompt Engineering
Prompt Engineering adalah cara menyusun instruksi agar AI menghasilkan jawaban yang tepat dan sesuai kebutuhan. Prompt yang baik memiliki empat bagian:
- Role: peran AI.
- Task: tugas yang diberikan.
- Context: informasi pendukung.
- Format: bentuk hasil yang diinginkan.

Prompt yang jelas dapat meningkatkan kualitas dan kendali terhadap hasil AI.

Git dan GitHub
- Git adalah sistem untuk melacak perubahan file atau proyek.
- GitHub adalah platform online untuk menyimpan repository Git dan berkolaborasi.

Git Workflow
1. Working Directory: tempat mengerjakan dan mengubah file.
2. Staging Area: tempat menyiapkan perubahan sebelum disimpan.
3. Git Directory: tempat Git menyimpan data dan riwayat proyek.

Perintah Dasar Git

| Perintah | Fungsi |
|---|---|
| `git init` | Membuat repository Git. |
| `git add .` | Menyiapkan perubahan. |
| `git commit -m "pesan"` | Menyimpan perubahan. |
| `git remote add origin <url>` | Menghubungkan repository online. |
| `git push origin main` | Mengunggah perubahan ke GitHub. |
| `git pull origin main` | Mengambil perubahan dari GitHub. |
| `git clone <url>` | Menyalin repository ke komputer. |

2. Poin Penting
- Prompt harus jelas, spesifik, dan memiliki konteks.
- Git digunakan untuk mencatat perubahan proyek.
- GitHub digunakan untuk menyimpan repository secara online.
- Perubahan proyek dikelola melalui proses add, commit, dan push.
- Git dapat membantu pengembangan proyek secara individu maupun kelompok.

3. Praktik Workshop
Workshop memperkenalkan pembuatan aplikasi sederhana **Student Task Planner** dengan tahapan:
- Menggunakan platform AI untuk membantu membuat aplikasi.
- Menulis prompt sesuai kebutuhan.
- Menjalankan `git init` pada folder proyek.
- lakukan commit dan push ke GitHub.
- Memperbarui proyek, lalu commit dan push kembali.
